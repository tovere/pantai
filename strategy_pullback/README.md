# 策略三：强势股回踩MA20低吸（买回踩，不买突破）

## 一、策略定义
**股票池**：主板，剔ST/科创/创业
**趋势前提**：收盘 > MA20 > MA60 且 MA60 上行
**回踩入场**：近10日曾≥MA20×1.05(有过上涨) + 今日最低探到MA20(low≤MA20×1.02)但收盘守住(close≥MA20) + 缩量(量<近5日均量)
**买入**：信号日收盘
**卖出**：收盘跌破MA20 或 −5%硬止损，先到先平

思路：策略2买"突破启动"，策略3反过来买"强趋势里的回踩打折点"——买在支撑、止损天然近。

## 三、关键发现（命门）
- **纸面比策略2强**：盈亏比4.0、收益更高、回撤更低、最坏单笔仅−11%（买在支撑止损近）。
- **但edge 100%靠肥尾**：剔最赚1% → −0.39%（转负），剔5% → −1.61%。比策略2(剔1%→−0.10%)**更依赖头部、更脆**。
- **Top大肉全是真的**（0数据毛刺，都是持有30~70天的真妖股趋势：嘉美包装+504%、长飞光纤、振德医疗…）。
- **胜率仅24%、更反人性**：99%交易在小亏放血，全靠~1%(一年全市场约6只)的5倍妖股覆盖。
- 结论：是策略2的"高辛烷值版"，潜力大但**更难兑现**（笔数少+更靠肥尾，5仓位易整年漏掉monster）。**最佳用法是和策略2合并分散**，见 [`../COMBINED.md`](../COMBINED.md)。
