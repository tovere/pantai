# 策略二：沿5日线趋势跟踪（站上MA5买入，跌破MA5卖出）

## 一、策略定义（最终版：B容忍 + −5%硬止损）

**进场（新突破）**
- 排除 ST/退、科创(688)、**创业板(3xx，无权限)** → 仅主板
- **上升趋势**：现价≥MA60 且 MA60上行（MA60[今] > MA60[10日前]）
- **连续3日收盘站上MA5（B容忍）**：单日浅破拉回不算断，连续2日收盘破MA5才算真破。第3天刚满 = 新突破
- 当天未大跌（跌幅≤5%，避开破位/出货）
- **排异动**：连续3日累计涨幅 <20%(主板)/<30%(创业板)，剔除被监管盯上的爆炒股
- 信号日涨停封死则买不进（回测已剔除）
- 买入：信号日收盘价

**持有/卖出（双止损，先到先平）**
- **MA5软止损**：连续2日收盘跌破MA5 → 卖（单日浅破不动，让利润奔跑）
- **−5%硬止损**：亏到买入价−5% → 无条件砍（盘中触止损价成交，跳空低开破则按开盘价）
- 持有周期不固定，平均约5.6个交易日

### 核心发现

1. **剔除涨停板后期望几乎不掉（+0.42%→严格+0.34%）。** 这是和策略一的根本区别——策略一剔涨停板后从+0.57%崩成−0.58%（edge全在买不到的板）；策略二的edge来自**多日持有+盈亏比**，是两套里唯一剔涨停板后仍正期望的。

2. **B容忍（单日浅破不算断）把单笔期望翻倍（+0.34%→+0.68%）**：少洗盘、持有更久。但纯B回撤飙到32%（多扛了真跌的前半段）。

3. **−5%硬止损是关键补丁**：把最坏单笔从−36%锁到−17%、底仓回撤从32%压回18%，单笔仍有+0.55%。**纯持仓的最优配置 = B + −5%止损（+28.4%/回撤18%）。**

4. **做T派例外**：若重度做T，严格版(+118%/回撤10.8%)略胜——做T吃周转，严格版周转快。

### 风险与执行难点

- **极度反人性**：胜率约31%=大部分时候在错、连续小亏。全靠守纪律(双止损)+拿住大牛股。多数人"小亏乱动、大赚早跑"，把正期望做成负的。
- **靠尾部**：+0.55%高度依赖赚>15%那批(含极端+357%)，漏掉大牛趋势期望就塌。
- 单年样本，未覆盖完整牛熊；2026年3月是最差月(胜率16%、−2%)。

## 三、做T叠加（高抛低吸，真实分钟数据验证）⭐

在底仓上叠加做T：持有期间**高开则开盘卖、盘中低点接回**，吃掉日内振幅；低开/平开不动。

### 叠加回测（吃幅33%，每笔平均做T 1.2次）

| 方案 | 胜率 | 均收益 | 中位 |
|---|---|---|---|
| 纯趋势(不做T) | 31.1% | +0.34% | −1.12% |
| **+做T 只做高开回落(安全)** | 38.0% | **+1.10%** | −0.70% |
| +做T 全做·全接到低点(乐观) | 39.3% | +1.31% | −0.65% |
| +做T 冲高日全卖飞(悲观) | 26.3% | **−0.67%** | −1.24% |

### 真实分钟数据验证（5分钟K线5177样本 + 1分钟分时161样本）

| 指标 | 5分钟 | 1分钟 |
|---|---|---|
| **卖飞率**(开盘≈最低,接不回) | 10.0% | 11.2% |
| —高开**冲高**日卖飞率 | 22.9% | 45.0% |
| —高开**回落**日卖飞率 | **1.1%** | **0.0%** |
| 平均可接回幅度 | 2.84% | 3.95% |
| 现实吃一半 | ≈1.57% | ≈2.22% |
| 低点出现在上午占比 | 63.4% | 63.6% |

### 核心结论

- **做T整体安全**：卖飞率仅~10%，90%的高开日都能接回更低价（两数据源一致）。
- **"高开回落必赚"被实测证实**：回落日卖飞率仅1%/0%——接回必赚，是稳赚的安全alpha。
- **风险只在"高开冲高日"**(卖飞率23%)：开盘卖了一路涨、追不回。
- **实战纪律**：**高开回落就做T(高抛低吸)，高开强势冲高就拿住别动**。可吃到约+0.76%安全alpha，避开削肥尾的卖飞风险。
- 实测"吃半≈1.5~2.2%/做T日"与回测"安全做T +1.10%"量级吻合，证明做T层是真实可吃到的，非日线虚高。
- **执行情报**：63%的接回低点在上午盘。

## 四、文件

| 文件 | 用途 |
|---|---|
| `screen.py` | **每日选股**：主板+上升趋势+连续≥3日站上MA5(B容忍)+非异动，输出"新突破(刚满3天)" |

## 五、概念

- **新突破 (fresh)**：刚满3天站上MA5（streak==3）。真正的新买点；站了10天、20天的是趋势中段，不是新进场点。
- **B容忍**：单日收盘浅破MA5拉回不算断，连续2日收盘破才算。减少洗盘。`hold[d]=收盘在线上[d] or 收盘在线上[d-1]`。
- **双止损**：MA5软止损(连2日破) + −5%硬止损(亏5%无条件砍)，先到先平。
- **距MA5 (bias5)**：`(现价/MA5−1)×100%`。越小越贴线=止损越近、风险越小；越大=已拉升、追高。
- **异动**：连续3日累计涨幅≥20%(主板)/30%(创业板)，交易所异常波动标准，剔除爆炒股。
