# 策略四：新高股回踩缩量低吸（成交额大的首次历史新高后的缩量回踩）

> 对仗策略三（强势股回踩MA20低吸）：策略三买"趋势中回踩均线"，策略四买"**首次历史新高放量后、次日缩量回踩不破**"——买在刚创新高的强票第一个回踩打折点，保护位天然贴近。

## 一、策略定义（盘面7条标准）

1. **昨/前天创真历史新高**：全history最高点落在最近2天内（`ghidx ≥ i-2`）。太早=加速位置驾驭不好，剔除。
2. **首次突破，非连续加速**：近10日里创新高的天数 ≤ 2（不是天天新高的加速股）。
3. **新高日放量**：创新高那天成交量 > 前5日均量（有资金，不是缩量阴跌新高）。
4. **昨日阳线 → 保护位**：昨天必须收阳，`保护位 = 昨日阳线最低点`。
5. **今日缩量回踩不破**：今日量 < 昨日量 且 ≥ 前5日均量×0.4（缩量但非崩量）；收盘 ≥ 保护位；今日涨跌幅在 −5%~+5%（小幅整理）。
6. **今日有承接（排出货）**：收盘价在当日振幅上半段（`close ≥ low + 振幅×0.5`），排除冲高回落出货。
7. **排妖 + 排加速**：近10日无单日 −6% 暴跌；近3日累计涨幅 < 30%。

**一句话特征**：成交额大的**首次历史新高**后的**缩量回踩**。

## 二、买卖

- **买入**：信号日收盘价；最优是盘中下杀回踩到保护位附近低吸（"距保护"越小越好）。
- **保护位/止损**：跌破保护位（昨日阳线低点）或 −5%，先到先平。
- **机会形态**：盘中分时跳一下、连续回踩不破、尾盘低吸埋伏，或等上证30F MACD回0轴再看。

## 三、回测结论 ⚠️

回测区间：2025-07-01 ~ 2026-06-29；数据直接使用项目 `data_cache/`（2025 起缓存），所以这里的新高是**缓存区间新高**，不是上市以来真历史新高。

| 指标 | 结果 |
|---|---:|
| 交易数 | 1558笔 |
| 胜率 | 9.4% |
| 单笔均收益 | +5.47% |
| 中位数 | -4.34% |
| 平均盈利/亏损 | +97.36% / -4.03% |
| 盈亏比 | 24.13 |
| 平均持有 | 29.9天 |
| 最好/最差 | +817% / -12% |
| 资金曲线(5仓) | -15.6% / 回撤29.2% |

结论：单笔均值很高，但**胜率极低、组合曲线为负**，收益几乎全靠少数超大肥尾。它更像“妖股候选池/观察池”，不适合按当前规则单独机械执行；至少需要再加趋势、市值/成交额排序、止盈或持仓筛选。

注意：选股器里的真历史新高会尽量取数据源能给的最长区间（东财自2017、腾讯约6年），非严格全A股上市以来；本回测按用户要求直接使用现有 2025 缓存，因此口径更宽。

## 四、文件

| 文件 | 数据源 | 说明 |

| `backtest.py` | 本地 `data_cache/` | 回测：复刻严格7条，保护位/−5%止损，5仓资金曲线 |

| `screen.py` | 东财 | 早期基础版（全主板，未按成交额排） |

### 运行
```bash
cd strategy_newhigh
python3 backtest.py      # 回测(使用项目现有缓存)
python3 screen_em.py     # 主用(东财)
python3 screen_tx.py     # 兜底(腾讯,含当日,不限流)
```

## 五、数据源注意

- 东财行情接口 `push2*.eastmoney.com` 在高频重试下会被限流（连接秒拒 http=000），冷却几分钟自恢复；翻页拉股票池最易触发。**被限流就切 `screen_tx.py`。**
- 各家**日K线源更新有先后**：盘后腾讯/新浪K线可能仍停在 T-1，需用实时接口补当日那根（`screen_tx.py` 已处理：K线末根非当日才拼实时，避免重复）。
