# Vben Admin Skills 技能库

快速生成常见业务模块的代码模板。

## 可用技能

| 技能 | 说明 | 适用场景 |
|------|------|----------|
| [CRUD 生成器](./crud-generator.md) | 标准增删改查模块 | 用户管理、角色管理、配置管理等 |


## 使用方式

### 方式 1: 直接描述需求

```
我需要一个用户管理模块,包含:
- 字段: 用户名、真实姓名、手机号、邮箱、状态
- 功能: 增删改查、批量删除、状态切换
```

### 方式 2: 引用技能

```
使用 CRUD 生成器创建角色管理模块
```

### 方式 3: 组合使用

```
创建一个商品管理模块(CRUD) + 销售数据仪表盘(Dashboard)
```

## 技能 vs 规则

| 类型 | 用途 | 触发方式 | 示例 |
|------|------|----------|------|
| **Rules** | 项目级硬性规范 | 自动触发 | 代码风格、命名规范、错误处理 |
| **Skills** | 可复用工作流模板 | 按需调用 | CRUD生成、表单生成、图表生成 |

## 注意事项

1. Skills 生成的代码遵循 AGENTS.md 中的规范
2. 生成后的代码可以根据实际需求调整
3. 建议先查看对应的 rules 文档了解详细规范
4. 所有生成的代码都包含完整的类型定义和错误处理
