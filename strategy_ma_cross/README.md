# 策略一：均线金叉 + 龙头过滤 + 次日卖

> 起因：用户看到社区有人用"2日均线上穿5日均线、现价≥13日均线、买入后第二天卖"的打法，5万做到14万。本目录是对这套打法的完整量化验证。

## 一、策略定义

**进场信号（信号日 D）**
- `MA2 上穿 MA5`：今日 MA2 > MA5 且 昨日 MA2 ≤ MA5（2日均线金叉5日均线）
- `现价 ≥ MA13`：收盘价站上13日均线

**买卖时点（A股 T+1）**
- 变体A：信号日 **尾盘按收盘价买入** → 第二天(D+1)卖出
- 变体C：第二天 **早盘竞价买入** → 再隔一天(D+2)卖出
- 不抗单：第二天无条件了结，不留隔日

## 二、数据源

| 源 | 状态 | 说明 |
|---|---|---|
| **东方财富** `push2his.eastmoney.com` | ✅ 采用 | 前复权日线(fqt=1)，全A约5500只，0失败 |
| 腾讯 `web.ifzq.gtimg.cn/fqkline` | ❌ 失效 | 返回 `No dispatch info found`，仅实时行情可用 |

纯标准库实现（无需 requests/pandas），多线程拉数据。

## 三、回测结论（核心）⭐

测试区间：2025-07-01 ~ 2026-06-29 全市场，往返成本 0.1%。

### 验证过程与结果

| 版本 | 单笔均收益 | 胜率 | 能否执行 | 备注 |
|---|---|---|---|---|
| 裸信号 尾盘买，次日卖 | −0.11% | 33% | ✅ | 无 edge |
| 龙头 尾盘买（**含涨停板**） | **+0.57%** | 48% | ❌ | **回测假象** |
| 龙头 尾盘买（剔除涨停板，真实） | **−0.58%** | 33% | ✅ | 全12月负 |
| 龙头 次日竞价买 | −0.21% | 44% | ✅ | 仍负 |
| 裸信号 次日竞价买，隔日收盘卖 | +0.15% | 48% | ✅ | 薄过滑点 |
| 裸信号 竞价买 + 条件卖(现实) | −0.06% | 44% | ✅ | 见下 |
| 裸信号 竞价买 + 条件卖(理想上限) | +0.80% | 53% | ❌ | 抓不到 |

### 关键发现

1. **那个漂亮的 +0.57% 是假象。** 龙头组里近一半信号是"信号日已封死涨停"的票——尾盘根本买不进。把这些买不到的票剔除后，真实可执行的龙头交易期望是 **−0.58%**，且**12个月全部负收益**。赚钱的部分恰好是你买不到的涨停板。

2. **换成次日竞价买，执行性解决了，但还是不赚。** 封板票次日普遍高开，你在竞价买等于为强势付溢价，期望从 −0.58% 改善到 −0.21%/−0.06%，逼近零但站不住真实滑点。

3. **"高开等最高点卖 / 低开10分钟砍"的条件卖：现实版 −0.06%，理想上限 +0.80%。**
   - 卖出日 **62% 低开**（−0.61%）、38% 高开（收盘卖 +0.84%）。少数高开盈利盖不住多数低开亏损。
   - "卖在最高点"是抓不到的天花板；它和"卖在收盘"之间约 2.3% 的差，就是**盘感alpha**——真实存在但无法机械复制。
   - 致命点：高开/低开是**买入后才知道**的，没法用来事前选票。

### 最终结论

> **这套机械策略没有散户可执行的正期望。** 所有"能真买到"的版本期望都在 −0.6% ~ +0.15% 的零附近窄带，最好的也扛不住真实滑点。社区大牛的盈利来自**抢板速度**和**分时盘感**（卖在冲高那一下）——回测做不出、也教不会的部分。这解释了"看着简单、大牛能赚、90%的人做亏"。

## 四、选股过滤链（screen.py 选股器）

每日 14:40 后扫全市场，过滤链：

```
剔ST/退/PT → 剔科创(688,无权限) → 金叉+现价≥MA13
→ 龙头(近10日涨停≥N次) → 剔下跌趋势(保留筑底) → 剔炸板
```

### 关键概念定义

- **龙头（代理）**：近10个交易日涨停次数 ≥ 阈值（收盘涨幅≥涨停线−0.5%）。**粗代理**，不分连板/散涨、不看板块地位、不看封单——只是"近期强势股"过滤。
- **乖离MA13**：`(现价/MA13−1)×100%`，现价比13日均价贵了百分之几。越大越超买/越烫手，越小越温和/抗跌。
- **趋势分类**：
  - 上升趋势：现价≥MA60 且 MA60上行
  - 站上MA60转好：现价≥MA60
  - 下跌中筑底（保留）：现价<MA60 但 MA20已拐头上行
  - 下跌趋势（剔除）：现价<MA60 且 MA60下行 且 MA20未拐头
- **炸板（剔除）**：当日最高价摸到涨停价、但收盘没封住（`high≥涨停价 且 close<涨停价`）。代表高位抛压重、分歧大，次日易低开走弱。

## 五、已知局限（结果偏乐观）

- **仅日线，无分钟数据**：抓不到"10分钟后卖""卖在最高点"等盘中择时；免费接口历史分钟数据只有最近几天。
- **成交假设理想化**：买卖按收盘/开盘价全额成交，未计真实滑点与冲击成本（小盘票竞价量小）。
- **涨停约束**：买入侧已剔除封板/一字，但卖出侧未模拟"一字跌停卖不出"，故真实更差。
- **单年样本**：2025下半年~2026是特定行情，未覆盖完整牛熊。

## 六、文件说明

| 文件 | 用途 |
|---|---|
| `ma_backtest.py` | 全市场回测：裸信号 vs 龙头，变体A/C，分月统计。改顶部参数测任意区间 |
| `screen.py` | **每日选股器**（14:40后跑）。完整过滤链，输出可操作清单 |
| `analyze.py` | 单只/多只技术面分析：`python3 analyze.py 002354 601958 ...` |
| `exit_rule.py` | 条件卖出回测：高开等最高点 / 低开开盘卖，跑理想上限vs现实 |

### 运行

```bash
cd strategy_ma_cross
python3 screen.py        # 今日选股
python3 ma_backtest.py   # 回测
python3 analyze.py 002354 # 单票分析
python3 exit_rule.py     # 条件卖出验证
```

## 七、参数（各脚本顶部可调）

- `SIGNAL_START / SIGNAL_END`：信号日窗口
- `DATA_BEG`：拉数据起点（给MA留热身）
- `ROUND_TRIP_COST`：往返成本，默认 0.001
- `LEADER_LOOKBACK / LEADER_MIN`：龙头回看天数/最少涨停次数
- `MIN_AMOUNT`（screen.py）：最低成交额，默认5千万
