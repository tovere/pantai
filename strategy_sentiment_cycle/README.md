# 策略十五：情绪周期（A 过滤器 + B 可执行打板）

用主板日线把市场状态收成五阶段，再接到两件事上：

- **A**：当策略 2/3（沿 MA5 / 回踩 MA20）的总开关
- **B**：独立打板。只买**回踩日收盘**或**次日开盘**，不买封死涨停、不买一字板

```bash
CACHE_ONLY=1 python3 strategy_sentiment_cycle/backtest.py
CACHE_ONLY=1 python3 strategy_sentiment_cycle/screen.py
```

## 口径（先读这个）

- 股票池 = `cache_data.universe()` **主板**（剔 ST / 科创 / 创业板）。本地缓存几乎没有创业板，这是「主板情绪」，不是游资软件的全 A 情绪。
- 涨停 = 收盘贴住 `round(昨收×1.10, 2)`（1 分钱容差），不用 9.5% 近似。
- **最高板会被单只老妖抬上去**（样本里锋龙股份 18 连板）。阶段判定用 2/3/4+ 板的**宽度**，不用最高板硬抬档。
- 2025-07 ~ 2026-08 这段主板结构偏热：窗口内冰点 2 日、修复 2 日。冰点/修复结论样本很小。

## 阶段怎么来

每日统计：涨停家数、跌停家数、最高连板、2/3/4+ 板宽度、晋级率、炸板率、昨日涨停竞价溢价、上涨家占比。热度 0–100 分档，从发酵/高潮回落标**退潮**。

| 阶段 | 含义 | A（策略2/3） | B |
|---|---|---|---|
| 冰点 | 涨停稀、溢价负、高位板少 | 关 | 回测更差，不抄 |
| 修复 | 刚从冰点/退潮抬头 | 关 | 回测为负，观察 |
| 发酵 | 宽度起来、溢价转正 | 开 | B1/B2 仍负；B3 勉强正 |
| 高潮 | 高位板变宽、热度高 | 开（不是空仓） | 禁止追板；B3 勉强正 |
| 退潮 | 从高位回落 | 降权 | 禁止买昨日涨停 |

## A. 状态过滤器

假设是「只在修复+发酵做趋势」。回测（主板缓存，2025-07-01~2026-08-21，往返成本 0.10%）：

| 过滤 | 笔数 | 胜率 | 均值 | 8仓收益/回撤 |
|---|---:|---:|---:|---:|
| 策略2+3 全时段 | 31229 | 28.8% | +0.38% | **+18.7% / 21.8%** |
| 高潮 | 13030 | 30.6% | **+0.55%** | — |
| 发酵 | 7050 | 28.8% | +0.44% | — |
| 退潮 | 11079 | 26.8% | +0.17% | −6.2% / 19.6% |
| 冰点 / 修复 | 22 / 48 | 13.6% / 12.5% | −2.90% / −4.11% | 样本小、明确差 |
| 只做发酵+高潮 | 20080 | 29.9% | +0.51% | +11.1% / 28.1% |
| **教科书·只做修复+发酵** | 7098 | 28.6% | +0.41% | **+1.2% / 19.0%** |

结论：

1. **教科书过滤是错的。** 修复+发酵才做，8 仓从 +18.7% 砍到 +1.2%。趋势策略吃的是肥尾，空掉高潮等于空掉 monster。
2. **高潮不是趋势策略的空仓信号。** 单笔高潮最好（+0.55%）。「高潮空仓」是打板纪律，不能套到沿 5 日线上。
3. **冰点/修复可以硬关。** 样本小但均值显著为负。
4. 落地：策略 2/3 **发酵/高潮照做，退潮降权，冰点/修复暂停**。不要为了「等修复」把仓停掉。

## A2. 接到盯盘台 5 / 10 / 11 / 12

脚本：`CACHE_ONLY=1 python3 strategy_sentiment_cycle/overlay_dash.py`

口径对齐 dashboard：5 个股宽松/严格、10 首中枢+lag≤2+risk≤12、11 VDB 宽松 ≥200 亿、12 的 2 档/3 档。5/10 用已有交易 JSON（到 2026-06），5 ETF / 11 / 12 现场跑到缓存最新日。这段样本几乎没有冰点/修复，「避开退潮」≈「只做发酵+高潮」。

| 策略 | 全时段胜率/均值 | 发酵+高潮 | 只做退潮 | 结论 |
|---|---|---|---|---|
| **5 ETF宽松** | 56.2% / +1.67% | **60.7% / +2.27%**（+4.5pp） | 45.2% / +0.19% | **升**。高潮 65.2%/+3.10% 最好；发酵反而弱 |
| 5 个股宽松 | 46.7% / +1.23% | **49.2% / +1.57%**（+2.5pp） | 40.5% / +0.39% | **升**。高潮最好，退潮明显差 |
| 5 个股严格 | 46.9% / +1.07% | **48.8% / +1.20%**（+1.9pp） | 41.3% / +0.69% | **升**，幅度小于宽松 |
| **10 个股三买** | 49.2% / +1.28% | **52.8% / +1.98%**（+3.6pp） | 42.2% / −0.10% | **升**。发酵 57.1%/+2.35% 最好；退潮均值转负 |
| 11 VDB宽松 | 56.7% / +2.43% | **58.2% / +2.50%**（+1.5pp） | 52.0% / +2.23% | **略升**。退潮均值还在，胜率掉 |
| **12 连小阳 2档** | 63.4% / +1.22% | 63.5% / +0.82%（均值掉） | **64.1% / +2.00%** | **过滤高潮会降均值**。退潮最好 |
| **12 连小阳 3档** | 62.5% / +0.93% | 61.1% / +0.41%（−1.4pp） | **65.8% / +2.02%**（+3.3pp） | **反过来**：避开高潮才升 |

盯盘台怎么用：

- 策略 **5 / 10 / 11**：高潮、发酵照做；**退潮少开或停**（10 退潮均值已负）。不要等「修复」才买。
- 策略 **12**：退潮可以做；**高潮降权**（未涨透票在过热市里更差）。
- 策略 **5 ETF**：最吃高潮；发酵单独看是弱的，别把发酵当 ETF 主升段。

## B. 独立打板（可执行约束）

全部剔除：信号日封死涨停、一字板、次日一字开盘。买点是回踩日收盘（B1/B2）或次日开盘（B3）。

| 策略 | 过滤 | 笔数 | 胜率 | 均值 | 8仓 |
|---|---|---:|---:|---:|---:|
| B1 首板回踩 | 全时段 | 4058 | 43.3% | **−0.50%** | −69.3% |
| B1 | 冰点+修复 | 32 | 21.9% | −5.98% | −8.7% |
| B2 二板回踩 | 全时段 | 457 | 39.4% | **−1.09%** | −50.1% |
| B2 | 修复+发酵 | 86 | 25.6% | −2.94% | −27.9% |
| B3 昨涨停→今开买收卖 | 全时段 | 13763 | 46.9% | −0.25% | −58.3% |
| B3 | 退潮 | 4719 | 41.6% | **−0.88%** | — |
| **B3** | **发酵+高潮** | 8914 | 49.8% | +0.09% | **+23.5% / 16.9%** |

结论：

1. **B1/B2 可执行回踩没有正期望。** 封板那天买不到的 edge 被丢掉之后，剩下的是亏钱的。筛选器仍会列出候选，只观察、不下单。
2. **B3 全时段做=慢性自杀**（8 仓 −58%）。退潮买昨日涨停均值 −0.88%。
3. **B3 只在发酵+高潮做** 是唯一能看的 B：单笔只有 +0.09%（盈亏比 1.06，成本已经吃掉大部分），8 仓 +23.5%/回撤 16.9%。edge 很薄，成本略升就会没。不当主策略。

这和策略一同一条教训：能执行的 edge 才算 edge。
