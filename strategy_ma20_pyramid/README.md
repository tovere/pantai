# 策略十二：上穿 MA20（胜率调优版）

冲约 **40%+ 胜率**：上穿建仓 + 多头排列 + 贴线 + 收盘位置过滤；**破 MA5** 离场。不加仓。

## 规则

| 项 | 定义 |
|---|---|
| 股票池 | 主板（剔 ST/科创/创业） |
| 入场 | 昨收 ≤ 昨 MA20 且 今收 > 今 MA20 |
| 结构 | MA20 > MA60，MA60 上行，**MA20 近 5 日上行** |
| 排列 | **MA5 ≥ MA10 ≥ MA20** |
| 大盘 | 上涨市（沪深300 ≥MA20且≥MA60，近20日涨幅≥0） |
| 贴线 | 收盘相对 MA20 乖离 ≤ **3%**（`BIAS_MAX`） |
| 收盘位置 | `(C−L)/(H−L) ≥ 0.55`（`CLOSE_POS_MIN`） |
| 出场 | **收盘破 MA5**，或 −5% 硬止损 |
| 加仓 | 关闭 |
